# Lumina Gallery

Локальный просмотрщик изображений, видео и аудио для Windows. Приложение работает напрямую с выбранной папкой: ничего не загружает в интернет и не копирует в собственную библиотеку.

## Возможности

- дерево папок и медиафайлов с ленивой загрузкой;
- галерея текущей папки или всех вложенных папок;
- комбинируемые фильтры «Фото», «Видео», «Аудио» и «Файлы» без повторного сканирования;
- виртуализированная сетка и системные миниатюры для больших библиотек;
- полный импорт с прогрессом до показа галереи;
- постоянный JPEG-кэш миниатюр и предварительный прогрев ресурсов;
- переиспользование карточек без сброса видеобуфера при прокрутке;
- одновременное воспроизведение видимых видео;
- автоматические 2,5-секундные WebM-превью 360p/12 FPS с постоянным дисковым кэшем;
- корректная перемотка локального видео через Range-потоки;
- регулируемый размер карточек;
- отдельный предпросмотр фото, видео и аудио;
- автоматический переход к следующему видео или аудио;
- системные обложки аудиофайлов, контекстное меню и открытие через стандартное приложение;
- три изменяемые по ширине зоны, сворачиваемые боковые панели;
- отслеживание изменений файловой системы;
- обновление файлов без перерисовки и мигания дерева папок;
- настраиваемые основные цвета и готовые цветовые темы;
- удаление в Корзину Windows с отключаемым подтверждением и открытие файла в Проводнике;
- клавиши `Ctrl+O`, `Delete`, `Space`, `←` и `→`.

## Запуск для разработки

Потребуется Node.js 20 или новее.

```powershell
npm install
npm start
```

## Сборка установщика Windows

```powershell
npm run dist
```

Готовый установщик появится в папке `release`.

## Примечание о видео

Декодирование выполняет Chromium внутри Electron. MP4/H.264 и WebM обычно воспроизводятся сразу; для редких контейнеров и кодеков поддержка зависит от конкретного формата файла.
