# Lumina Gallery

Локальный просмотрщик изображений, видео и аудио для Windows и Linux. Приложение работает напрямую с выбранной папкой: ничего не загружает в интернет и не копирует в собственную библиотеку.

## Возможности

- дерево папок и медиафайлов с ленивой загрузкой;
- галерея текущей папки или всех вложенных папок;
- комбинируемые фильтры «Фото», «Видео», «Аудио» и «Файлы» без повторного сканирования;
- виртуализированная сетка и системные миниатюры для больших библиотек;
- полный импорт с прогрессом до показа галереи;
- постоянный JPEG-кэш миниатюр и предварительный прогрев ресурсов;
- переиспользование карточек без сброса видеобуфера при прокрутке;
- одновременное воспроизведение видимых видео;
- воспроизведение GIF- и WebP-анимаций тем же переключателем, что и видео;
- автоматические 2,5-секундные WebM-превью 360p/12 FPS с постоянным дисковым кэшем;
- корректная перемотка локального видео через Range-потоки;
- регулируемый размер карточек;
- отдельный предпросмотр фото, видео и аудио;
- общий звук и громкость для всех плееров правой панели, с настройкой звука по умолчанию;
- плей/пауза по пробелу для последнего использованного плеера предпросмотра или полноэкранного видео;
- восстановление последней сессии: добавленные папки, раскрытое дерево и текущая папка (включается в настройках);
- автоматический переход к следующему видео или аудио;
- системные обложки аудиофайлов, контекстное меню, открытие файла и его папки;
- перемещение файлов перетаскиванием из галереи на папку в левом дереве;
- контекстное меню файлов и папок в дереве: переименование, создание папок и удаление;
- три изменяемые по ширине зоны, сворачиваемые боковые панели;
- отслеживание изменений файловой системы;
- обновление файлов без перерисовки и мигания дерева папок;
- настраиваемые основные цвета и готовые цветовые темы;
- удаление в системную Корзину с отключаемым подтверждением и открытие файла в файловом менеджере;
- встроенный редактор TXT и Markdown с сохранением и отменой несохранённых изменений;
- отдельное оформление распознаваемых текстовых файлов TXT и Markdown;
- прямое перетаскивание карточки: внутри окна — в папки Lumina, за границу окна — в Проводник или на рабочий стол;
- клавиши `Ctrl+O`, `Delete`, `Space`, `←` и `→`.

## Запуск для разработки

Потребуется Node.js 20 или новее.

```powershell
npm install
npm start
```

## Сборка установщика Windows

```powershell
npm run dist
```

Готовый установщик появится в папке `release`.

## Сборка для Ubuntu из Windows

Запустите Docker Desktop в режиме Linux-контейнеров, затем из папки проекта:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-ubuntu.ps1
```

Скрипт использует `electronuserland/builder:24` (Ubuntu 22.04), добавляет внутри Docker библиотеки для проверки Electron и виртуальный экран. Linux-зависимости и кэши сохраняются в Docker-томах; Windows-папка `node_modules` не изменяется. При повторной сборке зависимости переустанавливаются только при изменении `package-lock.json`.

После проверок в `release` появляются файлы `Lumina-Gallery-<версия>-linux-x86_64.AppImage` и `Lumina-Gallery-<версия>-linux-amd64.deb` для Ubuntu x86-64. На самой Ubuntu можно выполнить `npm ci`, затем `npm run dist:linux`.

Для установки DEB: `sudo apt install ./Lumina-Gallery-<версия>-linux-amd64.deb`.
Для AppImage: сделайте файл исполняемым (`chmod +x <файл>.AppImage`) и запустите его. На некоторых системах потребуется FUSE; альтернативный запуск: `./<файл>.AppImage --appimage-extract-and-run`.

Миниатюры Linux создаются встроенным FFmpeg. Перетаскивание во внешний файловый менеджер Linux использует правила этого менеджера; Lumina не удаляет исходники автоматически после такого перетаскивания.

Проверка воспроизведения, звука и восстановления сессии в Electron: `npm test`.
Исходник логотипа — `src/assets/logo.svg`; команда `npm run build:icon` обновляет иконки PNG и ICO.

## Примечание о видео

Декодирование выполняет Chromium внутри Electron. MP4/H.264 и WebM обычно воспроизводятся сразу; для редких контейнеров и кодеков поддержка зависит от конкретного формата файла.
